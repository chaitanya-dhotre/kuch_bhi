Values are the Warm Pop tokens (lib/core/theme/tokens.dart); laws are binding (see docs/design/00-foundation.md §6 and the acceptance checklist docs/design/pages/chat.md, which Astra implements against and review grades against). Search mechanics (pinned)
  • Decrypt-on-query via #body — every searched body goes through C1/MessageBodyText; never raw ciphertext, never a stored index.
  • Ephemeral — nothing persisted; closing search clears query + matches.
  • Match navigation wraps (last→first→…); Enter/Next-keyboard = next match.
  • Keyboard stays up through next/prev; only close dismisses it.
  • Terminal/key_missing bodies are searchable only by their decrypted text — no match on placeholder labels.

S20 · Accessibility, motion, scope

Floor + what is NOT in this page

A11y floor (chat page)
  • Every icon-only control: 48dp target + Semantics label (back/search/dots/attach/send/mic/chevrons) — today zero labels exist.
  • Contrast: body ink on surface ≥4.5:1; onAccent on accent ≥4.5:1 (checked both themes — inkSoft-on-accent at 66% used for timestamps passes ≥4.5 as alpha-composited; engine check in review).
  • Message rows expose a merged semantics label: sender + body/type + time + status — one swipe reads a row.
  • Reduced-motion: shimmer parks · typing dots freeze · pulse freezes · highlight = single fade · spring pops instant.
  • Text scale 1.3 must not clip app bar, ticks, or chip rows (review capture at font_scale 1.3).
