Part 1

Home + shared pieces

Unread rows keep one marigold spot (the badge); the time turns ink 600 (CR-1). Avatars get one look everywhere: surface2 + 1 dp ring (CR-8). The new-chat button slides away while scrolling down and returns on scroll up (the "after" panels show the list mid-scroll, CR-2). AMOLED: surface2 #0D0D0D → #171512, so discs show on black (A5). Count on device at rest: 9 marigold spots → 5.
A3

Buttons

Labels 600 (today 700). Tonal = bubbleMine + ink label, the same pair as an own chat bubble, so it passes 12.9 : 1 light and 10.7 : 1 dark.
Part 2

Settings, Profile, Edit profile

Settings barely changes: check discs and switches stay marigold (C5b), subtitles 12.5 → 13. Edit profile: the photo badge goes grey (CR-6). Theme change cross-fades over 250 ms instead of Flutter's 200 ms linear.
Part 3

Requests, Group info, New group

Accept is tonal, Decline secondary; an answered card fades and closes over 190 ms. Group info: Add is a small tonal button, Admin a grey pill, Leave group the only red. New group: chosen people pop in as chips above the list.
Part 4

Starred, Media & docs, Add a friend

Starred: "You" was marigold text at about 2 : 1 on white; it becomes inkSoft 600, and only the small star keeps a marigold (accentText). Media & docs: grey icon tiles and actions; the tab label is ink with a 2 dp marigold bar, the same tab bar as Add a friend. Auth already has one primary per screen; it only takes the button weight and token motion.
