H5 · Search pill (new — approved mockup, absent in code)

Closed · focused · filtering · no results

Closed
Search chats
Full-width pill under app bar (42dp, radius 999, surface + line border — R8 language but home-owned copy). Always visible (no icon-collapse mode — this list is short and scan-first).
Focused / typing
desig
Focus = accent border 1.5px (R8). Typing = live local filter, no debounce needed (in-memory). ✕ (only when text) clears + refocuses. Keyboard open → FAB hides (M3 default) and returns on dismiss.
Filter rules
  • Match = case-insensitive substring on conversation display name + friend names. NOT previews (previews decrypt — searching them would couple filter to #body; deliberate no).
  • Filters BOTH sections in place; section headers stay, counts update live; hidden sections collapse entirely.
  • Matches render in matching tiles normally (no highlight marks on home — chat owns mark language).
  • No results → per-section line “No chats match ‘{q}’.” / “No friends match ‘{q}’.” (12px inkFaint, centered); if both empty → single centered line + mascot NOT shown (empty-state mascot = zero-data only).
  • Clearing search restores exact scroll position. Ephemeral — never persisted.

H10 · Backup banner

One strip, two targets, law-pinned

Visible
Backup your encryption key to restore messages after reinstall. Tap to set up.
  • Copy EXACT (law L7) — verbatim string, not paraphrase.
  • Whole-strip tap (new target, law intent kept): any tap except ✕ → /backup-pin/setup (was text-only).
  • ✕ = dismiss writes backup_reminder_dismissed_at + invalidate (law L7) — 7-day window unchanged (law L6). Strip exits with 250ms fade.
  • Visibility = P6 tri-state gate exactly as-is (law L6): local key ∧ backup strictly false ∧ not dismissed ≤7d.
  • Load flash: provider “unknown” currently pops the banner in after resolve — new: hold hidden until first true value (no flash-in).
Placement
  • Top of body, above search pill (it outranks search — key-loss prevention > lookup). Full-width inset 12, radius 16, accentSoft fill.
  • Never renders over the list when dismissed — no reserved gap.
  • No success/counterpart banner (backup-done confirmation lives on the setup screen — out of scope here).

H11 · Body state rules (beyond the H3 specimens)

Loading · error · offline · refresh

Loading skeleton (NEW anatomy)
  • Per row: 40px circle + name bar (45–60% width) + preview bar (50–75%) — tile-shaped, not flat 56px blocks (foundation §6: mirror final layout).
  • 4 rows + “Chats” header bar; shimmer 1.4s (R11), parks under reduced-motion.
  • Trigger law stays (law L9): conversations loading, OR friends-loading with zero renderable convs.
  • Skeleton→content: instant swap (no crossfade — content is the truth).
Error + offline
  • Error = mascot(key mood) + “Couldn’t load your chats” + “Check your connection and try again.” + Retry (invalidates conversations + friendships — law L9). Replaces bare centered StatusBanner; copy replaces nothing that tests pin? — flagged: law L9 pins the old string ‘Could not load your chats.’ via StatusBanner — test update expected, listed in home.md gates.
  • Offline strip = chat S18 exact language + Retry (NEW on home). Sits above error block when both true; clears 250ms on reconnect.
  • Partial failure (friends error, chats OK) → inline mini StatusBanner above Friends header, chats untouched (SHOULD).
Pull-to-refresh
  • Accent spinner (not Material default color) — token-driven.
  • Refreshes conversations AND friendships (new — today only convs; friend tiles could lag).
  • Empty state becomes always-scrollable (AlwaysScrollableScrollPhysics) — refresh reachable on empty (new fix).
  • Failed refresh = silent (stream error surfaces via H3 error block) — no toast spam.
Scroll perf (W3 frame-drop rule)
  • ListView → ListView.builder (SHOULD): unbounded current children list; item keys for reorder animations when pin toggles.
  • No per-tile async work on build (avatar cache hits only — standing frame-drop rule).
  • Pin toggle animates row move 250ms (implicit — AnimatedList or simple rebuild; no bounce spring).

H12 · Accessibility, motion, scope

Floor + what is NOT on this page

A11y floor (home)
  • Semantics labels: title actions (“{n} pending requests”, “Your profile”), FAB “New chat” (tooltip doubles), search field “Search chats”, pin glyph (“Pinned”), presence dot merged into tile label.
  • Tile semantics = one swipe: “{name}, {preview or Online}, {time}, {n} unread, pinned”.
  • Contrast: accent time/badge onAccent ≥4.5 both themes; success “Online” on surface ≥4.5 (checked — success on white ≈3.4:1 → subtitle “Online” uses success at w600 13px = large-ish text; flagged for engine check; fallback inkSoft+success dot only if it fails).
  • Reduced-motion: shimmer parks (existing), pin move instant, banner fade instant.
  • font_scale 1.3 capture: title + badges + pill must not clip.
Out of scope (declared)
  • Mute (no API) · Delete/Archive conv (no data) · Select mode · swipe actions on tiles.
  • Invite-link / share-profile rows in new-chat sheet.
  • Sender-prefix for previews of non-text types (constants already carry the type; prefix only on text).
  • Sticky headers, collapse-on-scroll app bar, FAB badge.
  • AddFriendSheet internals beyond boundary (its own states inventoried but specced on page 8 — sheets).
  • Offline banner > companion/call states — chat S18 owns the copy; this page reuses it verbatim.
