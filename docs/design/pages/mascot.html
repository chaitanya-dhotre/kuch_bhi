The yuzu bath: offline banner (E1, idea I1)

Real capybaras soak in yuzu baths in Japanese zoos every winter. Here each message waiting to send is a yuzu in the pool. Mirrored so it faces the text.

State machine layers

Idle breathe 3.4 s; blink about every 4.6 s only while the eyes are round (curved eyes get a slow content squeeze instead) · Mood face sets, 150 ms fades · Action pet, hop, wave, celebrate, flush · Props z loop, sweat bob, steam.

Budget: one .riv ≤ 60 KB, no blur, at most one clip per artboard. One Capy Flutter widget loads it once; still placements park the Idle layer.
