S6

The waveform (E1–E4, C20; decision 6)

Source. One 100 ms tick while recording: elapsed = base + tick × 100 ms, and one getAmplitude() → waveLevel(dBFS) appended. Paused = no tick. 5 minutes = 3,000 numbers, kept in memory only.

Level. ((dBFS + 50) / 50) clamped to 0.06–1: silence and the −160 floor draw a 3 dp stub, a shout fills the height.

Bars. 3 dp wide, 2 dp apart, radius 1.5, centred. Live: newest at the right. Preview: bucketLevels takes the max of each bucket so peaks survive.

Stays on this phone (decision 7): the other side's bubble is unchanged.
