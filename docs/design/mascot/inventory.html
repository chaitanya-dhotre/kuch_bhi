2

What changed from C, and what's still open

  • New Head view for every slot under ~56 dp (banner, app bar, lock screen, icon). This was the main fix: the face goes from ~10 dp to ~25 dp at 40 dp.
  • Crisp muzzle shape instead of a gradient fade, bigger eyes, ears set wider so the silhouette reads as capybara and not bear.
  • Pear-shaped sitting body with a wider base, paws resting on the belly, one thigh line. Still sitting, still "on watch".
  • Yuzu smaller, outlined, and kept as part of the head, so it never outshines the face.
  • Still open after your pick: the polish pass (curves, paw shapes, the expression sheet), the Loaf view if wanted (D6), and checking on both phones in Phase 2.

4

Decisions (defaults in bold)

  1. Style: S1 Sticker / S2 Flat bold / C as first drawn.
  2. C4 host: the empty-chat capybara hops when the first message sends, then fades out. Alt: an app-bar buddy that hops on every send (noisy, costs frames while typing fast).
  3. The 12 places today: keep them; the 3 default ones go from 180 to 120 dp; still poses except the placements marked animated (one per screen).
  4. Typing indicator capybara: no.
  5. C2 swipe companion: drop (it would animate mid-gesture, the costliest moment on the Redmi).
  6. Loaf view: later, with onboarding.
  7. App icon: decide after Phase 2, from the Head view.
  8. Props: key only for now.
